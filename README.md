# Terceiro Projeto – Loja Online
Este projeto em Python foi criado para calcular os descontos de acordo com o valor total da compra.
O programa solicita o **valor_total, desconto e o valor_final** e, calcula o desconto que o cliente receberá dependendo do valor de sua compra.
Menor do que R$ 200,00, o cliente recebe um desconto de 5%.
Maior ou igual a R$ 200,00, o cliente recebe um desconto de 10%.
Maior ou igual a R$ 300,00, o cliente recebe um desconto de 15%..
